# MetaSwitch - 智能代理管理工具

MetaSwitch 是一个功能强大的 Chrome 浏览器扩展，帮助您轻松管理和切换多个代理服务器配置。

## 特性

### 🚀 快速切换
- 一键切换不同的代理配置
- 支持快捷键快速操作
- 直观的用户界面设计

### 🔧 灵活配置
- 支持 HTTP/HTTPS/SOCKS5 代理协议
- 自定义代理规则和自动切换
- 批量导入导出配置

### 🛡️ 安全可靠
- 本地存储所有配置数据
- 不收集用户隐私信息
- 开源透明，代码可审查

### 🌐 智能路由
- 基于 URL 模式的自动代理规则
- 支持通配符和正则表达式匹配
- 智能故障转移机制

## 快速开始

### 安装扩展
1. 从 [Chrome 网上应用店](https://chrome.google.com/webstore) 安装 MetaSwitch
2. 或手动加载开发者版本

### 基本使用
1. 点击浏览器工具栏中的 MetaSwitch 图标
2. 添加您的代理服务器配置
3. 选择并启用所需的代理

### 高级功能
- **规则配置**：设置基于 URL 的自动代理规则
- **快捷键**：使用键盘快捷键快速切换代理
- **批量操作**：一次性管理多个代理配置
