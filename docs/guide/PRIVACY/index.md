# 隐私政策

## 数据收集和使用

MetaSwitch 扩展尊重您的隐私，我们承诺：

### 收集的信息
- **零数据收集**：本扩展不会收集、存储或传输任何用户数据
- **本地存储**：所有代理配置和设置仅存储在您的浏览器本地
- **无网络请求**：扩展不会向任何外部服务器发送数据

### 权限说明
MetaSwitch 需要以下浏览器权限：

- **proxy**：用于设置和管理代理服务器配置
- **storage**：用于在本地保存您的代理设置和偏好

这些权限仅用于扩展的核心功能，不会用于其他目的。

## 数据安全

- 所有配置数据仅存储在您的浏览器本地
- 数据不会同步到云端或其他设备
- 卸载扩展时会自动删除所有本地数据

## 第三方服务

MetaSwitch 不集成任何第三方分析、广告或跟踪服务。
