# 快速开始

欢迎使用 MetaSwitch！本指南将帮助您快速上手使用这个强大的代理管理工具。

## 安装

### Chrome 网上应用店安装
1. 访问 [Chrome 网上应用店](https://chrome.google.com/webstore)
2. 搜索 "MetaSwitch"
3. 点击 "添加到 Chrome"

### 手动安装（开发者模式）
1. 下载最新版本的 MetaSwitch
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的 "开发者模式"
4. 点击 "加载已解压的扩展程序"
5. 选择 MetaSwitch 的文件夹

## 基本使用

### 添加代理配置
1. 点击浏览器工具栏中的 MetaSwitch 图标
2. 点击 "添加配置" 按钮
3. 填写代理服务器信息：
   - 名称：配置的显示名称
   - 服务器地址：代理服务器 IP 或域名
   - 端口：代理服务器端口
   - 类型：HTTP/HTTPS/SOCKS5

### 切换代理
1. 在代理列表中选择要使用的配置
2. 点击 "启用" 按钮
3. 代理状态将立即生效

### 配置管理
- **编辑配置**：点击配置项右侧的编辑图标
- **删除配置**：点击配置项右侧的删除图标
- **导入/导出**：支持批量导入导出配置

## 高级功能

### 规则配置
MetaSwitch 支持基于 URL 模式的自动切换规则：
1. 进入 "规则" 标签页
2. 添加新的规则
3. 设置匹配模式和对应的代理配置

### 快捷键支持
- `Ctrl+Shift+S` (Windows/Linux) 或 `Cmd+Shift+S` (Mac)：快速打开扩展面板
- `Ctrl+Shift+1` 到 `9`：快速切换到第 1-9 个代理配置

## 故障排除

### 常见问题

**代理无法连接**
- 检查服务器地址和端口是否正确
- 确认代理服务器正常运行
- 检查网络连接

**扩展无法加载**
- 重启浏览器
- 重新安装扩展
- 检查浏览器版本兼容性
